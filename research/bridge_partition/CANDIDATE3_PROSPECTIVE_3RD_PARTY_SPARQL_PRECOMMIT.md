## Frozen experimental protocol
1. Four independent Oxigraph RDF stores in separate OS processes connected over TCP; hard per-shard maximum storage = 1.1*mean physical NTriples serialized bytes, accounting for any replicas. Exactly same logical triples and Oxigraph engine as a separately loaded centralized reference. No unverified partial graph substituted as "full SWDF".
2. Entire RDF query string is passed unchanged to Oxigraph; correctness compares complete SPARQL answer multisets (including literal values and multiplicities) with centralized evaluator. Queries with regex-extraction ambiguities, property paths, unbound predicate variables, aggregates or unsupported features are excluded by a **fixed parser eligibility contract before splitting**; exclusions and counts reported. For any eligible query, all exact triple-pattern predicate groups must be fetched; if incomplete or failed, fail closed.
3. No trust in a first20/last20 split; SHA256 exact query strings and predicate-family disjointness verified with no leakage. Holdout by hash of predicate-set family, 20% strictly excluded, seeded `20261121`. For timestamped queries, chronological split takes priority, with duplicate-text and novel-pattern statistics reported separately.
4. Never optimize using test future. Train and calibration from disjoint 80%; fix objective, budgets, and source selection before unsealing test labels. No parameter sweep chosen after test.
5. Evaluated contenders at identical 4-shard raw byte cap and at most 25,000,000 move/replicate NTriples raw bytes: no migration, day0 greedy one-swap, day0 greedy two-swap, exact byte-efficient selective replica, swap+replica, and abstaining witness-calibrated admission using only train/calibration. WISE/WASP/MTGA comparisons must be *faithful executable implementations* with matched objective and version; proxy heuristics may NOT be misrepresented as them. If unavailable, paper SOTA superiority gate is BLOCKED, not PASS.
6. Measure actual transmitted NTriples, wall-clock migration+index updates, per-query serial and parallel complete end-to-end elapsed time, full answer equality for all eligible heldout, p50/p95/p99, throughput, all four-shard bytes, and live migration cutover correctness. No concurrent query during non-atomic migration means recovery/concurrency claims are BLOCKED.
7. Pair each same SPARQL query across policies with randomized order; independently resample unique query family (not execution repeats) for 95% CI, and use chronological day blocks where actual timestamps are present. At least 20 unique heldout query family clusters and >=50 complete nonempty heldout queries are required for a confirmation claim; else diagnostics only.
8. Strict article GO only if both: measured **net end-to-end improvement** including actual migration cost has 95% lower bound >0 against strongest executable equal-byte baseline at declared traffic horizon; and novel-family p95 and extra-shard traffic do not degrade beyond preregistered 1% tolerance. Report numerical accuracy and all failed exclusions, no cherry picking. Without real cross-host network and multiple timeshift cohorts, report lab-only, never production economics. An observed positive locality surrogate is NOT sufficient.
9. The previous WatDiv and Wikidata workloads are all OPENED and ineligible as independent tests. A failure to acquire aligned SWDF RDF graph and query-log artifact prevents a complete prospective test; it is NOT repaired by relabeling already-seen datasets.

## Method proposal to evaluate, not assume
Working candidate "witness-calibrated lower-bound migration admission": For a move S, only queries with a predicate in S can change routing. Estimate its gain separately on recent and historical novelty witnesses, reserve a calibration uncertainty penalty for distribution drift, subtract complete observed move/index overhead, and abstain (no migration) unless a positive net lower bound remains. Replication treated identically with its storage cost. Theoretical lemma is a triangle inequality, not novel by itself. Require non-vacuous calibrated bound and reproducible advantage over strong baseline before a novelty claim.

Decision language: PASS, FAIL, or BLOCKED for each gate, never a single misleading "PASS" from successful CI exit status alone.
