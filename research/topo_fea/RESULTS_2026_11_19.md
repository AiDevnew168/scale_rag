## Verified real-data coverage

The original source benchmark, manifest and layout-content archive were downloaded and SHA256-verified in GitHub Actions. 2,024 questions across 201 documents; the deterministic sample consists of 300 questions (180 bridge-chain, 120 synthesis) from 191 distinct documents. We parsed 67,349 original layouts from all 201 documents. All 300 selected questions were scored. The retrieval algorithms receive only user questions and document layout text/OCR/VLM-text descriptions. Gold evidence IDs, bridge entities, gold answers, and reasoning traces are ONLY used for evaluation.

This is a text-surrogate retrieval diagnostic, not direct image reading, not VLM answer generation, not a test against a real cross-encoder or FlowReader.

## Research gate

NO-GO for claiming that the tested graph heuristic or two-role lexical assignment demonstrates an algorithmic advance. Candidate-selection headroom is real, but no compelling improvement over the simple baseline has been shown. The broader role-and-consistency constrained retrieval hypothesis remains UNTESTED, not disproven.

A valid next gate requires a strong fixed-pool cross-encoder or multimodal reranker, independently verified relation-incompatibility annotations, exact CP-SAT/ILP versus simple matching/greedy with the same scores, document-held-out confirmation, and final VLM answer accuracy. Avoid expensive system development before satisfying these tests.
